# PiAgent project documentation

Project-specific agent notes, plans, procedures, and implementation records for the PiAgent configuration live under `agents/`.

Reusable, project-agnostic extracts belong in the repository-level `plans/`, `skills/`, `procedures/`, `subagents/`, `mcp/`, or `configs/` directories instead of this project-local documentation tree. Pi Subagents and Pi Teams share the `subagents/` definition library.
